# Tài nguyên và quyền sử dụng

28 ảnh/SVG được sao chép nguyên từ thư mục `images/` của repository hiện tại. CSS gốc cũng được sao chép để giữ giao diện. Không tải ảnh mới hoặc tự khẳng định người dùng sở hữu bản quyền.

Chưa thấy LICENSE hoặc tài liệu xuất xứ ảnh trong repo. Trước khi công khai/phân phối ngoài bài tập cần xác minh quyền dùng, bổ sung nguồn/tác giả/giấy phép hoặc thay bằng tài nguyên có quyền phù hợp. Google Maps iframe là thành phần có sẵn từ website cũ, cần Internet và có thể không hiển thị khi offline.

Ảnh do admin upload phải có quyền sử dụng; ảnh nằm ngoài Git, tên file do server sinh. Chỉ dùng dữ liệu người nhận/liên hệ giả khi demo hoặc chụp ảnh màn hình.
